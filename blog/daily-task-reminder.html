Feature guide

Set up the Blurts daily task reminder

Get a morning prompt to review your tasks, understand the 9:30am schedule, and distinguish the daily reminder from individual deadline alarms.

By the Blurts team November 9, 2026 3 min read

Bring the task list back into your day

Capturing a thought is useful only if you encounter the task again. Blurts offers an optional daily notification to help you return to the list. The current reminder is scheduled for 9:30am in your device’s local time and uses the task information available when the schedule is prepared.

This is a daily review prompt. It is not an alarm for each task’s due time, a location reminder, or an escalation that keeps ringing until an item is complete. Knowing that distinction helps you decide where a morning nudge fits and where you still need a separate time-critical reminder.

Enable the reminder after a successful capture

After your first successful save, Blurts may ask whether you want a daily reminder. Choose the affirmative option and allow notifications in the operating-system prompt. The phone ultimately controls delivery, so allowing the in-app prompt alone is not enough if notification permission is denied by the system.

If you choose Not now, the app postpones asking again. If you deny the system permission, it avoids repeatedly prompting you. To change a system-level denial later, use your phone’s notification settings for Blurts. The current flow does not provide a custom reminder-time picker; this guide describes the existing 9:30am schedule.

  • Allow Blurts notifications in your phone settings.
  • Open the app after changing tasks so its local schedule can refresh.
  • Use a dedicated alarm elsewhere for a critical exact-time commitment.

What the notification can say

When there are pending tasks for today or items past their date, the reminder can show counts and open the task list. When today’s tasks are complete, it can offer a prompt to capture more. With no tasks, it can suggest recording thoughts; those no-task nudges are capped rather than scheduled without limit.

The content is prepared from the local task store, then scheduled ahead. It is not a live server calculation at the moment the phone displays the notification. If your task state changes elsewhere or the app has not refreshed, the count in a scheduled notification can be older than the list you see when you open the app.

Use it as the start of a short review

Imagine you captured three follow-ups yesterday and have not opened your list this morning. The notification is a cue to check what is still pending. Open the list, review dates and priorities, complete anything already finished, and decide which item you will act on next. The value comes from that review, not from collecting another notification.

If the notification says you have nothing pending but you remember a commitment, open Blurts and inspect the list before assuming the task is gone. Check folded sections and the archive as well. Notification text is a convenient summary, while the task list is where you examine the actual records.

Troubleshoot a missing or surprising reminder

Check notification permission first, then whether your phone is suppressing alerts through its normal notification controls. Android delivery uses the operating system’s inexact scheduling behavior, so do not treat the reminder as a precision alarm. The schedule is prepared for a limited period ahead and is refreshed through app activity.

If the text is stale, open the app and refresh your task state. If you need a different time or one notification per task, those are different capabilities from the current daily reminder. Keep their absence explicit when deciding how to handle appointments or deadlines that require an exact alert.

Common questions

Can I choose a different reminder time?

The current implementation uses 9:30am and does not expose a custom-time picker.

Will I be alerted at each task’s due time?

No. The daily notification and task due times are separate features.

Why can the count differ from the list?

Notification content is based on local task state when scheduled, not a fresh server query at delivery time. Open the app to review the current list.

Try one real thought.

Start with something you actually need to do. Review the result and decide whether the workflow fits your day.
