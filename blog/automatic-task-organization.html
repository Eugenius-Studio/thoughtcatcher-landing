Feature guide

See tasks organized by date, type, area, and priority

Learn how Blurts classifies captured tasks and groups errands, waiting items, appointments, and completed work without requiring a filing session.

By the Blurts team November 9, 2026 3 min read

Let the list supply an initial structure

A mixed recording can contain work, errands, appointments, and things you are waiting for. Blurts gives those tasks an initial structure so they do not all arrive as identical lines. It identifies a type, an area, and a priority, then uses those details alongside dates to organize the task list.

The classifications are suggestions based on your words. They are useful when they reduce the work needed to review a capture, but they are not a judgment about your life or an automatic decision about what you should do. You can correct them through Edit when the initial interpretation is wrong.

Understand the available fields

The current task types are Task, Routine, Waiting On, Appointment, and Errand. Areas are Business, Health, Work, and Family. Priority is low, medium, or high. When urgency is unclear, the extraction defaults to medium priority. These are a defined set of fields rather than a custom tagging system where you create unlimited new categories.

After capture, open the list and examine a few representative items. An errand should describe an action you would do while out; an appointment should correspond to scheduled activity; a waiting item should represent something dependent on another person. If a task crosses areas, choose the classification that makes it easiest to find in your own review.

  • Use Edit to change Type, Area, or Priority.
  • Keep a due date only when it reflects the intended timing.
  • Treat Routine as a label, not a guarantee of automatic repetition.

How the list changes shape

The default order considers priority, then timing, then capture order. Several errands can be grouped under “While you’re out,” while waiting items collect in a folded section. Completed tasks have their own fold. A timed appointment can display its time prominently so you can recognize it quickly among the other items.

Area headings are used when there are enough open tasks across multiple areas to make grouping useful. Small lists can stay flat, with the area shown in each task’s details. This means two people with different task counts can see different amounts of structure without having enabled different features.

Try it with a real mixed capture

Imagine recording a document follow-up, two shopping errands, and a note that you are waiting for a colleague’s reply. Once the tasks appear, inspect the types and areas. The useful outcome is a list where you can recognize what you can do now, what belongs to a trip outside, and what depends on someone else.

If the waiting item was interpreted as a normal task, edit its type. If everything appears equally important, set priorities based on your actual commitments instead of adding urgency words to every recording. Classification is a starting point for deciding what to do, not a substitute for that decision.

Avoid reading extra automation into the labels

An Appointment label does not create a calendar event. A Routine label does not create an endless series of recurring tasks. Waiting On does not send a message to the person you named. These fields describe the task so the list can present it more usefully.

If you want a narrower view, use Lens to filter the existing areas or change the order. That changes what you see without moving the underlying tasks. If an item appears missing, check folded sections, the active Lens, and the archive before recording it again.

Common questions

Can I create custom task areas?

The reviewed editor provides Business, Health, Work, and Family. This guide does not claim arbitrary custom areas.

Will a Routine task automatically repeat?

No recurrence-generation behavior was found in the reviewed implementation. Routine is a classification.

Why do I see “While you’re out” only sometimes?

The organizer batches errands when multiple errands occur in a date group. A single errand can remain in the ordinary list.

Try one real thought.

Start with something you actually need to do. Review the result and decide whether the workflow fits your day.
