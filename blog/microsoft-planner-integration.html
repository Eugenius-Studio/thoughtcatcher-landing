Send spoken follow-ups to a Microsoft Planner plan

Connect Blurts to Microsoft Planner with a work or school account, choose a plan and bucket, and understand assignment and delivery limitations.

By the Blurts team November 9, 2026 3 min read

Put a spoken follow-up where the team manages work

Blurts can deliver captured tasks to a selected Microsoft Planner plan and bucket. This is useful when commitments arise in a conversation but the team’s work is tracked in Planner. The goal is a new Planner task in the chosen destination, rather than a voice note that you still need to rewrite later.

This is a Microsoft Planner integration, not a Microsoft To Do integration or a general connection to every Microsoft 365 service. The current flow requires an eligible Blurts paid account, a supported Microsoft work or school account, and access to an available Planner destination. Organization permissions can affect whether connection succeeds.

Connect and choose the plan and bucket

Open Blurts settings and select Microsoft Planner. Complete Microsoft authorization using the work or school account that has access to the relevant plan. In Choose Planner destination, select a plan, wait for its buckets to load, choose a bucket, and use the destination confirmation control.

After connecting, settings shows the selected plan and bucket and offers Change plan or bucket. Check those names before sending real work. If the app reports that no plans are available, confirm the account and plan access. If it reports Reconnect required, address authorization before interpreting the saved destination name as evidence of a live connection.

  • Use the account that belongs to the intended organization.
  • Choose a specific plan and bucket before testing delivery.
  • Confirm a newly created task in Planner after a small test capture.

What a delivered task can contain

The current delivery path sends the title, description, due information, and mapped priority. It can include the captured area as context in the description. Explicit assignment language can also supply a requested person’s name; simply mentioning someone in the task does not mean the task should be assigned to them.

Assignment requires a unique exact match against available group-member identity details. If the requested person cannot be matched uniquely, the request is preserved as description context rather than silently choosing a different person. Check the actual assignee in Planner when ownership matters, and use a sufficiently specific identity in your spoken instruction.

Test a team follow-up without assuming the result

For example, record a harmless action to review a draft and explicitly name the intended assignee only if you want assignment. Inspect the Blurts result and the Planner delivery state, then open the chosen plan and bucket. Confirm the title, owner, priority, and due information there. This is a setup exercise, not a claim that a connected settings screen proves successful delivery.

The capture flow can also let you exclude individual tasks from Planner when the connection is available. That matters for a recording containing both work and personal intentions. Check those choices before completing the delivery step so a household errand does not become a team task merely because it was spoken in the same session.

Keep the synchronization boundary clear

The current Planner path creates tasks from captured Blurts items. Later Blurts edits, completion changes, and deletions are not promised to update Planner. Manage those delivered tasks in Planner when needed. Likewise, this guide does not claim that Planner changes return automatically to Blurts.

If a delivery fails, check authorization, entitlement, and the selected destination. A task can remain saved in Blurts even if Planner delivery fails. An expired authorization message means reconnecting is necessary; repeatedly recording the same intention is not a substitute. Start with one test item after reconnecting and inspect the actual Planner result before relying on the workflow for a batch of commitments.

Common questions

Does this also connect Microsoft To Do?

No. This feature targets Microsoft Planner plans and buckets. Microsoft To Do is a different product.

Can I use a personal Microsoft account?

The current flow is designed for supported work or school accounts with Planner access and applicable organization permissions.

Does completing a task in Blurts complete it in Planner?

The Planner integration delivers new tasks. Later completion, edits, and deletions in Blurts do not update Planner, and Planner changes do not automatically return to Blurts.

Try one real thought.

Start with something you actually need to do. Review the result and decide whether the workflow fits your day.
