Feature guide

Edit, complete, reopen, and delete tasks in Blurts

Keep captured tasks accurate with Blurts’ task editor, completion controls, undo, and clear behavior for connected destinations.

By the Blurts team November 9, 2026 3 min read

Make the captured task match the real commitment

Speech capture is a starting point. You may need to correct a name, make a vague action more specific, or change a date after your plans move. Blurts gives you a task editor so that the item you review tomorrow reflects what you actually intend to do, rather than an imperfect first interpretation.

The current capture flow saves before showing its results. That means editing belongs in the main task list. You can also complete a task, reopen a completed item, or delete something you do not want to keep. Each action has a different meaning, so choose the one that matches what happened.

Use the task menu to edit details

Open the task’s menu and choose Edit. You can change the title, optional description, type, area, priority, date, and time. Use the title for the action you will recognize at a glance, and the description for supporting context. A blank title cannot be saved, so leave a clear action even when you remove unnecessary detail.

For example, “Talk to Alex” may become “Ask Alex to confirm the venue.” Add the date only if there is a genuine deadline. Change the type to Waiting On when the next step belongs to someone else, or back to Task when you have an action of your own. Save and inspect the item in its list context.

  • Use the menu for Edit; tapping the task row can change completion.
  • Use a date first when adding a clock time.
  • Review the list again after changing a field that affects grouping.

Complete work and correct an accidental completion

You can complete a task using its completion control or the supported swipe action. Completed work moves into a folded done section. A brief Undo action appears after completion; use it immediately if the gesture was accidental. You can also reopen a completed item by toggling it back to pending.

Completing a task is a record of work you consider done. It does not perform the action described in the title. Marking “Email the supplier” complete will not send an email. If the work is still needed but the wording is wrong, edit it rather than completing it just to clear the visible list.

Delete deliberately

Use Delete when a task should no longer exist, such as an accidental duplicate or an action you have decided not to keep. Blurts asks you to confirm deletion. This is different from completing a task or finding an old item in the archive. Do not rely on a completion Undo control as a general recovery mechanism for deletion.

For tasks linked to Notion or Google Tasks, Blurts attempts corresponding changes in those destinations: edits, completion changes, and deletion handling. Notion deletion is handled by archiving the linked page. These external operations can fail separately from the change inside Blurts, so inspect the destination if consistency matters.

Know where synchronization ends

The current Microsoft Planner workflow delivers newly captured tasks; this guide does not promise that later Blurts edits, completion, or deletion update Planner. Manage a delivered Planner task there when needed. Likewise, an outbound update to Notion or Google does not establish that edits made in those tools automatically return to Blurts.

If a change appears locally but a connected copy differs, check the connection and the destination. Avoid repeatedly deleting and recreating tasks as a substitute for diagnosing a failed update. Keeping a single place where you decide whether work is complete helps prevent conflicting copies from becoming a second task to manage.

Common questions

Can I type corrections?

Yes. The editor includes title and description text fields. That does not mean there is a separate typed-new-task capture screen.

What if I complete the wrong task?

Use the brief Undo action or open the done section and toggle the item back to pending.

Do changes in Notion automatically return to Blurts?

No reverse-sync guarantee is established here. The documented flow is Blurts-initiated updates to linked destinations, subject to connection success.

Try one real thought.

Start with something you actually need to do. Review the result and decide whether the workflow fits your day.
